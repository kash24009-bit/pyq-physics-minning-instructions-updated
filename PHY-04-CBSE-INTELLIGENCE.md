## 3 · How answer books are marked NOW (VERIFIED — 2026 board marking scheme, general instructions; the 2026 Chemistry scheme already in the Chemistry project, rules are board-wide)

1. **On-Screen Marking (OSM)** for Class XII from the 2026 exam. Answer books are scanned and marked on screen; the system totals the marks. (Also REPORTED widely; CBSE circular dated 9 Feb 2026.)
2. **Both options now count.** If a candidate attempts both alternatives of an internal-choice question, the examiner marks both and **the system keeps the higher score.** An unattempted alternative is marked "NA".
3. **An error is penalised only once.** "No marks to be deducted for the cumulative effect of an error." If a wrong value from part (a) is used correctly in part (b), part (b) still earns its method marks.
4. **Competency answers:** "In Class-XII, while evaluating two competency-based questions … even if reply is not from marking scheme but correct competency is enumerated by the candidate, due marks should be awarded." Answers "based on latest information … and/or innovative" can also earn marks.
5. **Value points are guidelines, not the complete answer.** A student's own correct expression earns the marks.
6. **The full scale must be used.** "Please do not hesitate to award full marks if the answer deserves it."
7. **Examiner workload:** 8 hours a day, **20 answer books per day** in main subjects. That is about 24 minutes per book, so answers must be easy to mark: numbered, labelled, results boxed, units present.
8. **Marking mechanics:** part-marks go on the right, whole-question marks on the left. Totally wrong = cross and zero. Examiners are warned against tick-but-no-marks errors.
9. **Photocopy of the answer book** is available to candidates on request, for a fee (as the 2026 scheme states).
10. **Reading time:** 15 minutes. The paper is handed out at 10:15; writing starts 10:30. (2026 paper; REPORTED via the printed instructions reproduced on answer sites.)

**2006 marking-scheme book, same principles 20 years earlier (VERIFIED):** "highlights the main value points and does not represent a complete ideal answer". Examiners were told to consult the Head Examiner before crediting answers absent from the scheme. Head Examiners re-check each evaluator's first five scripts.

## 6 · Identity clues inside the files (VERIFIED on real files)

- **Paper codes:** Physics = series 55 (55/1/1, 55/3/2 …). Blind/VI papers carry letter codes. Compartment papers sit in separate "COMPTT" folders.
- **2026 marking-scheme footers carry an internal code `YY-SS-SSN`**, e.g. `26-03-43N` = 2026, series 3, subject 43. For Physics expect `26-0x-42N`. This proves the year even when the file name doesn't.
- **Some schemes cover several sets in one file,** e.g. "Q.P.CODE 56_2_1,2,3", with underscores instead of slashes.
- **File names lie constantly.** In the Chemistry project, 80 of 81 names had no year; "…Main_paper.pdf" was a 2023 marking scheme; "…English.pdf" was a 2026 marking scheme; "56_4_2.pdf" was the scheme for 56/4/1-2-3.

## 7 · What each fact changes in this project

| Fact | Consequence in the project |

| Both-options-higher-score (2026) | The OR-pair register (R12) also records which alternative is faster, and briefs flag OR pairs where attempting both is realistic. Whether the rule continues in 2027 is unknown; flag it, don't assume it. |
